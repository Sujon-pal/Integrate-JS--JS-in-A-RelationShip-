What are the different ways to select an element in the DOM?
You can select elements using methods like getElementById, getElementsByClassName, getElementsByTagName, querySelector, and querySelectorAll.
What is the difference between innerHTML, innerText, and textContent?
  • innerHTML returns the HTML inside an element as a string, including tags.
  • innerText returns the visible text of an element, respecting CSS styling and line breaks.
  • textContent returns all text inside an element, ignoring CSS styling.
What is event delegation in the DOM?
Event delegation is a technique where you attach a single event listener to a parent element to handle events on its child elements, instead of adding listeners to each child individually.
What is event bubbling in the DOM?
Event bubbling is when an event triggered on a child element propagates up through its parent elements in the DOM hierarchy, allowing parent elements to handle events triggered by their children.
How do you create, add, and remove elements using JavaScript?
  • Create an element: document.createElement('tagName')
  • Add an element: parent.appendChild(element) or parent.insertBefore(element, reference)
  • Remove an element: parent.removeChild(element) or element.remove()
